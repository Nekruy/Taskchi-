| Роут | Поведение |
|---|---|
| `GET /api/academy/lessons/[id]` | + `blocks[]` по `order` (QUIZ без ответов) и `blockProgress[]` (`blockId, done, attempts, completedAt, data`) |
| `POST /api/academy/blocks/[id]/complete` | 401/403/404; TEXT/VIDEO — upsert прогресса → `{ done, attempts }`; QUIZ — `{ answers }` (длина = число вопросов, иначе 400) → `{ score, total, passed, passScore, required, results[{correct, explanation, isRight}], attempts }`; повтор — `attempts += 1`, последняя попытка в `data` |

## 4. UI — `c333516`
- Страница урока: если блоков нет — как раньше (`contentMd`); если есть — `contentMd` остаётся первым TEXT-блоком, **кроме** случая, когда среди блоков есть свой TEXT (тогда `contentMd` скрыт — без дублей). Блоки по порядку: TEXT — Markdown + «Дальше ↓» (`TextBlockDone`), VIDEO — YouTube nocookie / `<video>` + «Дальше ↓», QUIZ — `QuizBlock`.
- `QuizBlock`: карточка «Проверь себя · 5 вопросов · нужно 3 правильных · нужен для завершения урока» → «Начать»; по одному вопросу с прогрессом «Вопрос 2/5», варианты перемешиваются при каждой попытке (храним порядок отображения → исходный индекс; на сервер уходят исходные), после выбора ответ зафиксирован, «Дальше →»/«Завершить»; финал — «4 из 5 — тест пройден ✓» с разбором по каждому вопросу (ваш ответ, правильный, объяснение) или «2 из 5 — попробуйте ещё раз» + «Пройти заново» и «Перечитать урок» (скролл вверх); при уже сданном тесте — свёрнутая карточка «Тест пройден · 4/5 · Попыток N · Пройти ещё раз». Клавиатура: 1–4 выбор, Enter — дальше. Кнопки во всю ширину.
- Кнопка «Отметить пройденным» (`LessonNavClient`) — `disabled` с подсказкой «Сначала пройдите тест», пока тест не сдан; после сдачи активируется и подсвечивается (`animate-btn-pulse`) по событию `lesson:quiz-passed`.
- Sidebar урока и список уроков на странице трека — «✓ тест» у сданных (на треке у несданных — «· тест»).
- `/learn` «Продолжить»: если тест текущего урока начат, но не сдан — «Пройти тест урока N →».

## 7. Отклонения и решения
1. **«Мгновенно зелёный/красный после выбора»** — невозможно без раскрытия `correct` клиенту (ТЗ требует его не отдавать). Сделано: после выбора ответ фиксируется («Ответ принят»), а зелёный/красный с объяснением показывается на экране результатов по каждому вопросу. Если важнее мгновенная подсветка — вариант: отдельный `POST /blocks/[id]/check` на один вопрос (ответ сервера всё равно раскрывает `correct` после выбора, но не до).
2. Урок 1 в проде уже был отмечен вами пройденным до появления теста — гейт работает только на новые завершения; прошлый прогресс не откатывал.
3. TEXT/VIDEO-блоки не блокируют завершение урока (решение 3: блокирует только тест) — «Дальше ↓» лишь фиксирует прочтение для будущего XP.
4. `/learn` «Пройти тест урока N» показывается, когда тест **начат** и не сдан (прочтение `contentMd` не трекается — у неявного TEXT нет блока).
5. Повторная попытка перезаписывает `data` последней; история попыток не хранится (решение 2) — только `attempts`.

## 8. Риски
- Перемешивание на клиенте + отправка исходных индексов: если ученик откроет DevTools, он увидит только свои ответы — правильные не утекают; но `results` после попытки раскрывают все ответы, т.е. вторую попытку можно сдать «по памяти» (пересдача без ограничений — по ТЗ).
- `order` блоков без unique — `move` при равных значениях разводит на ±1 (как у уроков).
- Сид ставит QUIZ на `order 100`; админский блок с `order` авто = max+10 → добавленные после сида блоки идут после теста; порядок правится ↑↓.
- Клавиши 1–4 глобальны на странице урока (игнорируются в полях ввода) — при открытом чате Устода фокус в textarea, конфликтов нет.

## 2. Логика и API — `04dbe70`
`lib/learn.ts`:
- **Серия** — дни активности из `LessonProgress.completedAt` + `MentorMessage.createdAt (role=user)` + `LessonNote.updatedAt` за 400 дней; считается от сегодня, а если сегодня активности нет — от вчера (серия не «сгорает» до конца дня).
- **Курсы** (`getCourseCards`) — прогресс, обязательные уроки (без TASK), следующий урок, состояние задания `NONE | READY | PENDING | APPROVED | REJECTED`, оставшиеся уроки.
- **План** (`schedulePlan`) — оставшиеся уроки текущего трека (ACTIVE с наибольшим прогрессом, затем остальные ACTIVE) раскладываются по выбранным дням недели от даты плана (не раньше «сегодня − 7»); окно показа «сегодня − 7 … сегодня + 7»; прошедшие и не пройденные — `overdue` → «перенесено». Если дней выбрано больше, чем `daysPerWeek`, берутся первые; если не выбрано — с понедельника.
- **Достижения** — 🎓 Выпускник (по треку), ✍️ Первый промпт, 🔥 Неделя подряд (≥ 7), 📝 Первое задание, 💬 Разговор с Устодом, 📚 Половина пути (≥ 50 %); с датой получения где она есть и ссылкой.
- **Overview** — всё для главной одним вызовом; **диалоги с Устодом** через `groupBy` по уроку; **номер сертификата** `TA-` + 8 hex sha1 от `enrollmentId`.

`app/api/learn/*` (все 401 без сессии, только свои данные, zod на PUT/POST): `overview`, `status` (`enrolledCount` для навбара), `plan` GET/PUT (1–7 дней, дни 0–6), `prompts` GET (`?tag=&q=`) / POST, `prompts/[id]` PATCH / DELETE (чужой → 404), `notes` GET (`?lessonId=` или все) / PUT (upsert; пустой текст удаляет; 403 без записи на трек), `achievements`, `mentor`, `assignments`. `lib/learn-session.ts` — `requireUser()` для API и `requireLearnSession(path)` для страниц (редирект на `/login?callbackUrl=<точный путь>`).

3. Пункт «Академия» в NAV кабинетов заменён на «Учёба» (не добавлен рядом) — в bottom-nav кабинетов пять слотов.
4. `PromptSchema` не экспортируется из route-файла (Next запрещает лишние экспорты) — схема продублирована в `prompts/[id]` как partial.

## 8. Риски и долги
- Overview делает ~10 запросов к БД на открытие `/learn` — на сеульском dev это 2–5 с; на проде (eu-central) быстрее. При росте — кэшировать серию/достижения.
- Заметки и промпты не ограничены по количеству (только 20 000 / 10 000 символов на запись).
- Сертификат легко «подделать» внешним видом, но номер проверяем только по URL (нет страницы проверки по номеру).
- К12 rate limiting — PUT заметок каждую секунду при наборе (debounce 1 с) — нагрузка низкая, но без лимита.
- Печать: проверена только CSS-правилами (скрытие шапки/футера, A4 landscape), визуально в браузере не смотрел.

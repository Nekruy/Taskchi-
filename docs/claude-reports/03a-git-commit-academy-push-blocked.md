## ЗАБЛОКИРОВАНО: push

`git push -u origin feature/academy` отклонён классификатором auto mode (причина: Out-of-Place Publication). Обход не предпринимался.

Ветка `feature/academy` на `origin` отсутствует — она локальная. Резервной копии в удалённом репозитории **пока нет**; работа сохранена только в локальном git.

Что уйдёт при разрешении push: 4 коммита (`dd8fe45` логотип + три новых) в **новую** ветку `origin/feature/academy`. `main` и `origin/main` при этом не меняются — оба на `169e9cb`.

## НЕ сделано: перенос логотипа в main

Явного подтверждения на push в `main` не было («Отлично» в следующем сообщении отнесено к отчёту, а не к разрешению), поэтому перенос не выполнялся. `main` и `origin/main` — на `169e9cb`, как и были. Railway деплоит из `main`, значит новый логотип на прод **ещё не попал**.

План при подтверждении (без `git checkout main` — иначе незакоммиченные файлы перетащились бы на main; сейчас дерево чисто, так что риск снят):
```
git branch -f main feature/academy   # было бы fast-forward
git push origin main
```
Внимание: сейчас это перенесёт в `main` уже **не только логотип**, но и все три новых коммита Academy. Если нужен именно логотип — только cherry-pick:
```
git checkout main && git cherry-pick dd8fe45 && git push origin main
```
